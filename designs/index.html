FUTR Design Proposals

Twelve start-page concepts (plus two variants) for futr.space. Each folder holds a static homepage plus a Universe page (Honorverse) and a Civilization page (Manticore 1903 PD) in the same design. Content is sample data from data/; all lists are built for a growing catalogue.
